# PyInstaller Build Backup

This folder preserves one complete PyInstaller packaging snapshot for `ball_simulation.py`.

本文件夹用于保留 `ball_simulation.py` 的一次完整 PyInstaller 打包现场。

## Structure

## 目录结构

```text
pyinstaller_build_backup\
  build\ball_simulation\
  dist\ball_simulation.exe
```

- `build\ball_simulation\`: intermediate build files generated by PyInstaller.

  PyInstaller 生成的构建中间产物。

- `dist\ball_simulation.exe`: packaged Windows executable.

  打包后的 Windows 可执行文件。

## Notes

## 说明

These files are useful for inspecting the historical packaging state, dependency analysis, warnings, and the generated executable. They are not required to run the source version of the program.

这些文件适合用于查询历史打包状态、依赖分析、警告信息以及已生成的可执行程序。运行源码版本时并不需要这些文件。
